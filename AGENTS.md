# Agent Instructions for the Cyberfus Project

This document provides instructions and guidelines for AI agents working on the Cyberfus project.

## Project Overview

This is a Next.js application that uses Firebase for backend services and Tailwind CSS for styling.

## Development

*   **Dependencies:** Use `npm install` to install the project dependencies.
*   **Running the development server:** Use `npm run dev` to start the development server.
*   **Linting:** Use `npm run lint` to run the linter. Please fix any linting errors before submitting your changes.
*   **Testing:** Use `npm run test` to run the test suite. Please add tests for any new features or bug fixes.

## Environment Variables

This project requires environment variables to connect to Firebase. Please see the `.env.example` file for a list of required variables.

## Code Style

This project uses ESLint to enforce a consistent code style. Please adhere to the rules defined in the `.eslintrc.json` file.

## Commits

Please write clear and descriptive commit messages. Follow the conventional commits specification if possible.
