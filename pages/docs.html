Quickstart (Next.js)

Get started with Cyberfus in a Next.js application in just a few minutes.

1. Install packages

Install the Cyberfus CLI and the runtime packages via npm.

npm i @cyberfus/edge @cyberfus/runtime
cyberfus init

2. Configure Edge

Set up the Cyberfus middleware in your middleware.ts file to protect your routes.

// middleware.ts
import { cyberfusEdge } from "@cyberfus/edge";

export default cyberfusEdge({
  rules: ["ssrf", "prompt-injection", "pii-output"],
  egressAllow: ["api.openai.com", "vectordb.internal"],
});

3. Add Runtime Protection

Wrap your API handlers with the runtime shield to inspect inputs and outputs.

// api/chat.ts
import { withRuntimeShield } from "@cyberfus/runtime";

export default withRuntimeShield(async (req, res) => {
  // your handler; shield inspects inputs/outputs
});
